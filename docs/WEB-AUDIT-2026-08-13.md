# Zelené Mokrance - audit webu

Dátum auditu: 2026-08-13
Auditovaná verzia: https://www.zelenemokrance.sk/
Zdroj: verejný frontend, WordPress REST API, Elementor/Novamira read-only introspekcia a Lighthouse mobile audit.

## Zhrnutie

Web dnes komunikuje pozemky, rodinné domy aj byty. Hlavné menu má osem položiek a hlavná stránka /pozemky/ neexistuje. Najvyššia priorita je odstrániť demo prvky a opraviť dôveryhodnosť navigácie; až potom prestavať obsah na predaj pozemkov.

## Potvrdené zistenia

### Navigácia a obsah

- Menu obsahuje Domov, Domy, Byty, Galéria, Referencie, Štandard, Partneri, Kontakt.
- Rovnaký menu strom je priradený k main-menu, top-menu a mobile-menu-hed6; ďalšie lokalizácie sú rozdelené na ľavú a pravú časť.
- Menu položka Domov má URL http://zelenemokrance.sk, hoci WordPress home aj siteurl sú https://www.zelenemokrance.sk.
- /pozemky/ vracia 404 stránku.
- /domy/ obsahuje päť rodinných domov s cenami 275 000 až 278 000 eur.
- /byty/ používa interaktívnu mapu a zoznam bytov.
- /galeria/ má Elementor image-gallery s 37 položkami: 6 dronových fotografií a 31 renderov alebo obrázkov bytoviek.
- Domovská stránka má image-gallery s 36 položkami, z toho 6 dronových fotografií a 30 renderov.
- Referencie a Partneri sú samostatné stránky s krátkym obsahom, vhodné na zlúčenie do bloku O nás.
- Štandard je stránka technického štandardu domu, nie technickej pripravenosti pozemkov.

### Demo a dôveryhodnosť

Na frontende sa zobrazujú Compare listings, Compare, Login, Reset Password a text User registration is disabled for demo purpose. Footer obsahuje © 2024 a sociálne ikony. Aktívne sú Houzez Login Register a Houzez Functionality.

Potvrdené kontajnery sú `#compare-property-panel`, `#login-register-form` a `#reset-password-form`. Demo texty nie sú uložené v obsahu stránok ani vo vyhľadaných wp_options; generuje ich Houzez modul za behu. Text požiadaviek zadaný do zadania sa vo verejnom obsahu nenašiel.

### YellowPencil a CSS

- Child theme `houzez-child/style.css` obsahuje iba import parent theme, nie vlastné pravidlá.
- WordPress Customizer Additional CSS je prázdne.
- YellowPencil 7.6.0 generuje globálny inline blok približne 3,8 kB z option `wt_css` a ďalšie per-page pravidlá z `_wt_css`/`_wt_styles`.
- Publikované pravidlá obsahujú najmä rozloženie hlavičky, skrytie sociálnych ikon/adresy/breadcrumbov, Image Map Pro pozície, status štítky a accordion úpravy.
- Draft stránka Byty obsahuje historické MailChimp/WPForms pravidlá a do nového hardening modulu sa nemigruje.

### Hardening pripravený v GitHube

- `mu-plugins/zelene-mokrance-frontend-hardening.php` skrýva demo compare/login/register/reset UI na verejnom frontende.
- Rovnaký modul odstráni YellowPencil generovaný frontend CSS a nahradí iba preskúmané published-page pravidlá verziovaným CSS.
- YellowPencil options a post meta sa nemažú, takže rollback zostáva možný a editor v wp-admin/live preview zostáva dostupný.
- Modul opravuje aj starý root odkaz Domov na `home_url('/')`.
- Kód je uložený v GitHube; produkčný deploy ešte neprebehol, kým nebude potvrdený presný `SFTP_TARGET`.

### Kontakt a GDPR

Aktívny Contact Form 7 formulár je ZM kontakt, ID 20171, slug kontaktny-formular-1. Má meno, email, predmet a správu; odosiela na site admin email. GDPR checkbox v definícii formulára chýba.

### Technické chyby a SEO

- Homepage nemá meta description.
- Menu používa HTTP URL na Domov.
- Lighthouse mobile: Accessibility 87, Best Practices 77, SEO 92.
- Lighthouse zachytil 404 na /wp-content/uploads/2025/05/Mapa_2025_v02.jpg.
- Niektoré staršie media URL z galérie vracajú 404 pri priamom overení; galériu treba po redukcii znovu prejsť.
- Dronové obrázky sú dostupné vo WebP a majú responzívne varianty.
- Nie všetky staršie renderové položky majú platný moderný asset.
- Alt texty sú často prázdne a niektoré tlačidlá a sociálne odkazy nemajú accessible name.

## Odporúčaný cieľ menu

Pozemky / Lokalita / Galéria / Kontakt

O nás má byť krátky blok na home alebo v Kontakt.

## Priorita

1. P0: odstrániť demo compare/login/register UI, opraviť Domov na HTTPS a zjednotiť host.
2. P0: zredukovať menu a rozhodnúť o redirect/noindex pre staré URL.
3. P1: vytvoriť /pozemky/ s tabuľkou parciel, mapou, PDF a CTA.
4. P1: doplniť siete, technickú pripravenosť, regulatívy, čo je v cene a proces kúpy.
5. P1: upraviť kontaktový formulár a mobilné CTA.
6. P2: zredukovať galériu na reálne fotografie, video a 2 až 3 rendery.
7. P2: WebP/responzívne zdroje, lazy-load, alt texty a 404 cleanup.
8. P2: meta title/description, Open Graph a právne údaje v pätičke.
